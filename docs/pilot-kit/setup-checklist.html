Setup day checklist
Restaurant:   Date:  

A · Before the visit (Thaliyo)

  • Lead stage in Super Admin is Won; restaurant created (Create restaurant → Create and start trial)
  • Owner has set the password from the invite email
  • Menu received (photo / PDF / Petpooja export) and typed into the spreadsheet template
  • GSTIN, legal name, address, phone (they print on every bill)
  • Prices include GST or not? Round-off on? Packaging charge for takeaway?
  • Table list (e.g. T1–T12, seats)
  • Staff list: name, email, role (waiter / kitchen / cashier / manager)
  • Printer model known; 58 or 80 mm; USB or Bluetooth
  • Devices confirmed: counter tablet/laptop, kitchen tablet, waiter phones (Android, Chrome)
  • Staff WhatsApp group exists; owner adds us

B · Setup in the Business panel (with the owner)

  • Your business: name, GSTIN, address, GST included or not, map location
  • Your menu: upload the spreadsheet (or Import from Petpooja); fix any rows it left out under Menu
  • Sizes and add-ons for the dishes that need them
  • Tables: From T1 to T…, seats
  • Your team: everyone invited (each gets an email)
  • Settings: round-off, packaging charge
  • Google review: outlet’s Google Place ID (Place ID Finder) → Test link → print the table cards
  • Owner's phone saved, so the night summary goes to them

C · Devices (one by one)

DeviceWho signs inCheck
Counter tablet / laptopCashier (or manager)Staff app installed (Add to Home screen) · outlet chosen · printer paired, Test print OK · receipt paper set · cash drawer opens on a cash bill
Kitchen tabletKitchenOpens on Kitchen · 🔔 Sound on · screen stays on · on charge · loud enough over the exhaust
Each waiter's phoneThat waiterOwn login (never shared) · installed on home screen · language chosen · sees the tables
Owner's phoneOwnerBusiness panel opens · can sign in to the staff app too

D · Test run before going live (15 minutes)

  • Cashier opens the day with the real drawer cash
  • Waiter sends a 2-dish order from a table → kitchen rings → Start → Ready → waiter sees Ready
  • Waiter asks for the bill → cashier bills it with a discount → printed bill checked (name, GSTIN, GST, round-off)
  • Takeaway with packaging charge; UPI payment; split payment
  • Wi-Fi off → one takeaway billed → Wi-Fi on → it syncs
  • Sold out from the kitchen → the waiter can't add the dish → set Available again
  • Printed bill shows the “Review us on Google” QR; scan it with a phone: the restaurant’s review page opens
  • Manager voids the test bill, cancels the test orders

F · Go-live day

  • Be there (or on call) for the first lunch or dinner rush
  • Keep the old system / paper pad nearby for the first day only, just in case
  • First night: watch the day close with the cashier; the owner gets the WhatsApp summary
  • Send the staff welcome message in their WhatsApp group
  • Log a visit on the lead in Super Admin, with anything to fix
